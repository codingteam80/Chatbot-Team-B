DocuBot v6.5.5.1 - KB Update Notification UX Hotfix
======================================================================

Scope
-----
This hotfix changes only the successful Update Knowledge Base toast shown to
the operator. The v6.5.5 incremental KB lifecycle, source-stability guard,
worker lock, UI layout stability, retrieval pipeline, completion diagnostics,
and model/configuration invariants remain unchanged.

Expected success notification
-----------------------------
Knowledge Base is successfully updated.
Added: <N> · Updated: <N> · Deleted: <N>

The normal UI toast must NOT expose technical implementation details such as
chunk counts, unchanged/skipped counts, Qdrant/BM25 activation, semantic Rule
index status, or KB Health details. Those remain available in logs/evidence.

Manual smoke
------------
1. Modify Employee_Leave_Test.txt (or another harmless test source).
2. Confirm and run Update Knowledge Base once.
3. Verify the normal layout remains stable.
4. Verify the success toast contains only the success sentence and
   Added/Updated/Deleted counts.
5. Verify logs/kb_update still contain full technical evidence.

No production KB rebuild is performed by this patch installer.
