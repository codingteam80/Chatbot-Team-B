DocuBot v6.4.96 — Prompt Strategy Smoke
==============================================

Purpose
-------
Add behavior-only few-shot prompting plus silent grounded reasoning guidance
without changing the production RAG architecture.

Default profile
---------------
- Few-shot prompting: ON
- Silent grounded reasoning guidance: ON
- Visible chain-of-thought: OFF / never requested
- MultiQuery: remains ON from v6.4.95
- MultiQuery alternatives: 2
- MIN_RETRIEVAL_SCORE: 0.55 unchanged
- Vector/BM25/Final Top-K: 10/10/3 unchanged
- Chunking: 900/150 unchanged
- KB rebuild: not required

A/B switches
------------
Single-query baseline:
  set DOCUBOT_MULTI_QUERY=0

Disable few-shot examples:
  set DOCUBOT_FEW_SHOT_PROMPT=0

Disable silent reasoning guidance:
  set DOCUBOT_REASONING_GUIDANCE=0

Prompt design
-------------
The few-shot examples teach behavior only:
- permission question -> direct Yes/No polarity
- classification -> category only
- rationale -> rationale only
- unsupported fact -> strict fallback
- MISRA uncertainty -> Needs more context
- comparison -> compare exact statements
- MultiQuery -> intent-preserving search rewrites

The examples are explicitly marked as NOT COMPANY KNOWLEDGE and must not be
used as factual evidence.

The reasoning guidance is an internal evidence checklist. It does not ask the
model to reveal chain-of-thought, scratch work, or intermediate analysis.

Then compare quality/latency using the environment A/B switches above.
