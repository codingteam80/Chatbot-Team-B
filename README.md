# Company Knowledge Assistant

Private Offline Company Knowledge Search

## Features

- PDF
- DOCX
- XLSX
- PPTX
- TXT
- CSV
- HTML
- XML
- MD

## Stack

- Streamlit
- LlamaIndex
- Ollama
- ChromaDB
- BM25
- bge-reranker-large

## Build Index

```bash
python scripts/build_index.py
```

## Run

```bash
streamlit run app.py
```
