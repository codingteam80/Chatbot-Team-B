ACTIVE SCOPE
1. MISRA-first behavior. Other data/all_documents topics remain supported.
2. Natural/intention-based MISRA code-compliance assessment for varied
   English, Tagalog, mixed-language, pasted C/C++ code, and text scenarios.

SAFETY CONTRACT
- MISRA compliance mode filters accepted candidates to MISRA-named sources.
- qwen2.5:7b is used for natural compliance assessment unless the QA-only
  forced-model override is intentionally active.
- Rule/Directive identifiers in the answer must be present in accepted MISRA
  evidence; invented identifiers cause the safe no-result fallback.
- An explicitly requested MISRA C++ family cannot be answered from the current
  MISRA C-only source.
- Exact ordinary Rule/Directive lookups remain on the existing structured path.
- Secondary company-document questions remain on the existing general path.

CHAT INPUT
- Enter = send.
- Shift+Enter = newline.
- Multiline pasted C/C++ code is preserved.
- While an answer is processing, the editor remains writable but the send
  button/plain-Enter submit remains disabled.
