OBSOLETE TEST/RELEASE ROOT CLUTTER
----------------------------------
Exact, unmodified old release markers, old component manifests, superseded
validator scripts, the old v6.5.1 benchmark BAT/scripts/bank, and the obsolete
rebuild_index.py entry point are archived by the installer under:

    evidence\release_history\v6.5.5_final_cleanup_<timestamp>\

If any historical file was manually modified, the installer leaves it in place
instead of overwriting or moving unknown user changes.
