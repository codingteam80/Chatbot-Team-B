DocuBot v6.4.72 — Windows-safe Chunking-v4 Production Promotion
=================================================================

Trigger
-------
Actual office v6.4.71 promotion failed only at the final Windows directory
cutover with WinError 5 (Access is denied) while moving the validated staging
directory to storage\option_c_qwen3_qdrant_v4. Certified v3 and Experimental B
were preserved.

Fix
---
- Keep source validation, SQLite read-only backup, row-count checks, and staging
  validation unchanged.
- Publish the validated staging tree by copy to a fresh destination instead of
  Path.replace()/directory rename.
- Write metadata\v4_production_ready.json only after final validation.
- Default settings select production v4 only when that ready marker exists;
  otherwise they keep using certified Experimental B.
- Automatically repair an uncertified partial production-v4 destination from a
  prior failed promotion when it is not locked.
- Never delete/rename the certified v3 rollback or Experimental B source.

Office step
-----------
Close DocuBot windows, apply this patch, then run once:

  Promote_Chunking_v4_To_Production.bat

Expected ending:

  [PASS] Chunking-v4 is ready as the v6.4.72 production baseline.

No KB rebuild or pip install is required.
